# Modern resume templates

All three templates use the same resume facts in `content.tex`; edit that one file to keep the variants synchronized.

- `01-executive.tex`: restrained executive layout for leadership and senior-individual-contributor applications.
- `02-research.tex`: editorial research profile, with more room for patents and technical depth.
- `03-technical.tex`: compact, high-information-density layout for applied-AI and engineering roles.

Build a template from this directory with `latexmk -lualatex 01-executive.tex` (replace the filename as needed).
